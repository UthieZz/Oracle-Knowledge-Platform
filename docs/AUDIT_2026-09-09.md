# Audit 2026-09-09 — Oracle Knowledge Platform

Repo inspected: `UthieZz/Oracle-Knowledge-Platform` (requested name `Orackle-Knowledge-Platform.git` does not exist).

OKC compiler, importers, analyzers, and KnowledgeObject constructor call sites were not edited.

## Findings

### Weak / broken

- KnowledgeObject provenance is an untyped dict. Importers often copy conversation provenance and leave `evidence=[]`.
- FirestoreExporter previously published every KO as `type=conversation` and `conversation_id=object_id`. That collapses object identity into conversation identity and drops evidence.
- `tests/test_grok_single_file_and_provenance.py` has a pre-existing assertion bug: `next(c.id for ...).id` — `next` already yields a string.
- Firestore tests cannot run in a bare environment (`google.cloud` missing). Client is constructed in `FirestoreExporter.__init__`, so import itself requires credentials/SDK.
- KnowledgePackage getters return live mutable lists. No identity index; `get_conversation` / `get_attachment_knowledge` are O(n).
- KO model is conversation-shaped. AttachmentKnowledge has richer lineage than KnowledgeObject.
- Entities published without provenance.

### Obsolete / redundant

- Dual UI stacks: `src/ui` (desktop) and `studio/` (web) plus `src/studio`. Historical, not removed.
- Flask / `api_server` migration leftovers should stay until Firestore read path is verified. Not deleted.
- `output/` and `output_split/` committed compiled artifacts inflate the repo (~60k). Packaging, not compiler.

### Scale / strengthen (not done here)

- Lazy Firestore client construction so tests and portable export do not import GCP at module load.
- Deduplicate KnowledgeObjects by stable id on `add_knowledge_object`.
- Grounded chat citation verification against KO.evidence / provenance.message_ids.
- Do not add vector DB, Docker, or a second compiler.

## Implemented

- `src/validators/knowledge_object_provenance.py`: deterministic repair of KO lineage from package conversations and attachments.
- `ExportService` runs repair before exporters; optional `strict_provenance`.
- Firestore KO documents now publish `type`, `conversation_id` from provenance, and `evidence`.
- Tests in `tests/test_knowledge_object_provenance.py`.
